# React + Node.js Docker Practice

A simple React frontend and Node.js/Express backend project created for learning and practicing Docker and Docker Compose.

## Tech Stack

* React
* Node.js
* Express.js
* Docker
* Docker Compose

## Run the Project

Build and start the containers:

```bash
docker compose up --build
```

Stop and remove the containers:

```bash
docker compose down
```

## Purpose

This project was created to practice:

* Dockerfiles
* Docker images
* Docker containers
* Docker Compose
* Running frontend and backend in separate containers
